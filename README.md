# Exames Davi

Site estático em HTML, CSS e JavaScript para acesso aos laudos médicos em PDF.

## Estrutura

- `index.html`: página principal
- `styles.css`: estilos responsivos
- `script.js`: pesquisa dos documentos
- `laudos/`: arquivos PDF
- `vercel.json`: configuração de publicação e cabeçalhos de privacidade
